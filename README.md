1. **Launch the Playbook:** Open `src/playbook.html` in your browser (or use VS Code Live Server) to open the interactive timer and have it as a mission guide.

3. **Open Gemini:** Open a browser tab to [Google Gemini](https://gemini.google.com) for running your final `OracleAsJudge` evaluations.
