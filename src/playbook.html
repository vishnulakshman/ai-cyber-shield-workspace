Arena Rules & AI Governance

Mandatory Execution Protocol

RULE 1: MANUAL CRAFTING ONLY (NO AI ASSIST)

Participants MUST NOT use any AI assistant (Copilot, Gemini, ChatGPT, Claude) to write or brainstorm attack prompts or Blue Team defense rules.

  • Manually analyze specification files.
  • Craft Red Team attacks using human natural intelligence.
  • Engineer Blue Team rules in .github/copilot-instructions.md manually.

Because automated test frameworks (e.g. Promptfoo) are omitted for local execution, participants can use Google Gemini strictly as an OracleAsJudge for final Metamorphic Invariance evaluation.

  • Copy your tests/eval-suite.md rubric contract.
  • Copy Copilot's generated Output 1 ($O_1$) and Output 2 ($O_2$).
  • Paste into Google Gemini with the Judge Prompt to get your official score.

Metamorphic QA & Prompt Drift

Target Files: specs/password-policy.md, tests/eval-suite.md, and copilot-instructions.md

The "10-Second One-Row Scan" Technique

Don't read entire generated paragraphs! Scan both chat outputs for **ONE single test case**: An 8-character password with missing numbers (e.g., "Abcdefgh"). If Chat 2 dropped this row to be casual/fast, **Check 2B fails (Score: 3/4 - FAIL 🔴)**.

Red Team Attack Phase (12 Mins)
1. Baseline Run (P1 - Formal):

Run P1 in Chat 1. Confirm it tests Length (<8 chars) AND Complexity (no numbers). Tick Boxes 1A & 1B in eval-suite.md.

2. Paraphrase Attack (P2 - Casual Dev):

Clear chat. Run P2 ("Act as a fast developer..."). Observe Copilot drop the missing-numbers check to be brief. Check 2B stays blank (Score: 3/4 - **FAIL 🔴**).

Blue Team Defense Phase (8 Mins)

Add the **Metamorphic Invariance Guardrail** to .github/copilot-instructions.md forcing Copilot to retain length AND complexity checks regardless of user brevity requests.

Clear chat, re-run P2. Confirm Copilot retains the missing-numbers check (Check 2B = PASS 🟢, Score: 4/4).
